## 核心：token 变成几何

`data.js` 的 `window.DEMOS` 有七种预置任务：检测、指代、计数、点、OCR、文本定位、抠图。
文件注明这些是模型输出的回放，页面本身没有为此执行在线模型请求。

1. 一个任务包含 `id / label / task / image / prompt / response`，抠图任务额外有 `matte`。
2. `tokenize` 把 `<...>` 标签保持完整，普通文本拆成较短片段；用安全的文本节点呈现。
3. `<ref>` 与 `</ref>` 之间累积对象标签，并为同类分配一致颜色。
4. `<box>` / `<point>` 决定当前模式；数值 token 范围为 0–1000。
5. 盒子凑齐四个数，点凑齐两个数就出现。原站在数量凑齐时触发，并非等关闭标签再一次性画完。
6. 覆盖层用百分比定位：归一化数字除以 10 得到百分数。图片与覆盖层所在 stage 保持同一宽高比。
7. `<OBJ>` 让事先准备的透明图显露；`None` 切为无匹配状态；计数任务还从最终文本读出总数。
8. `runId` 在重播或切换时增长。异步步骤核对身份，防止旧回放覆盖新任务。
9. 初次进入视口（threshold 0.35）开始；自动轮播在完成后停留约 3–4.2s，手动切 tab 后停止自动切换。

它最值得复用的是“同一份数据、同一个事件进度、两种同步表达”，而不只是终端外观。

## 源码存在，但当前 HTML 未挂载的模块

JS 565–627 中有图像对比滑杆：指针位置驱动 `--pos`，`clip-path` 裁切顶部图片；
`setPointerCapture` 支持拖拽；可选的初次扫动从 50% 到 82%、22%、50%。
JS 629–637 还保留画廊过滤。

当日 HTML 没有 `#compare` 或 `#galleryFilters` 对应界面。应将它们称为“源码里的可选模块”，
不能把代码存在当成网页当前正在展示，也不应据此要求每个生成页面都加入滑杆和画廊。

## 基于审阅的改进建议，不冒充原站已有行为

- 原站全局 `.reveal` 默认隐藏；新实现采用渐进增强，避免脚本失败后正文消失。
- 原站读取一次 reduced-motion；新实现监听变化，并提供覆盖 CSS、打字、RAF 与轮播的统一开关。
- 保留离屏暂停，再处理 `visibilitychange`、组件卸载与重复初始化的清理。
- 照片加载或 decode 失败应显式报错；陈旧任务在异步等待返回后、修改布局之前就退出。
- 完整 tabs 键盘操作、panel 关联、lightbox 焦点管理与焦点恢复是新实现应补足的内容。
- 强调色、比例、标签、数据与时序应按目标内容调整，不能把源站论文结论或人物直接移到别的项目。
